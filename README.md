# GMDGE
GameMaker Danmaku Game Engine

This is a game engine I made for anyone who wants to create danmaku games. All assets can be found by extracting the `.yyz` file.

Alternatively, you can obtain the source code, although some game-specific resources are still included.

## How to Use

1. Open the game and make sure your custom stage controller exists.
2. Select **Practice Start**. **Game Start** will only transport you to the test room.
3. Select your stage and play as you wish. You can add custom assets as needed.

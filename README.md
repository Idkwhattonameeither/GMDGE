# GMDGE
GameMaker Danmaku Game Engine
 This is a game engine that I made for anyone to make danmaku as they please. All assets can be found when extracting the .yyz file.
Alternatively, you can get the source code instead. Many items are stil included.

== How to use ==
 Step 1. Open the game. Make sure your custom stage controller exists.
 Step 2. Select Practise Start, as Game Start only transports you into the test room.
 Step 3. Select your stage, and play as you wish. You, of course, can add custom assets however you like.
